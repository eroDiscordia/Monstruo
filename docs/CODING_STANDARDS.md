# Monstruo Coding Standards

**Version:** 1.0.0-alpha.1
**Status:** Initial Standard

## Naming

- `snake_case` for modules, functions and variables.
- `PascalCase` for classes.
- `UPPER_CASE` for constants.

## Type Hints

Public functions should use type annotations.

## Imports

Order imports as:

1. Future imports
2. Standard library
3. Third-party
4. Monstruo modules

## Documentation

Update documentation in the same milestone as the code.

## Verification

Every change must be verified before it is considered complete.
